# BrandReview Monitor

Веб-приложение для мониторинга отзывов и рейтингов брендов Amebli, Sofino и Matrasroll, а также конкурентов на украинских review-площадках.

## Что умеет приложение

- Показывает сводку по брендам: рейтинг, количество отзывов и просмотров.
- Собирает и отображает отзывы с активными ссылками на источник.
- Фильтрует отзывы по бренду, источнику, тональности и периоду.
- Отдельно показывает сводный рейтинг по Vidhuk.ua и Google.
- Сравнивает ваши сайты с конкурентами:
  - Matroluxe
  - Expert-Matras.ua
  - mebelok
  - Дубок
  - Світ Матраців

## Подключённые источники

Основной рабочий источник:

- Vidhuk.ua

Дополнительные источники:

- 048.ua
- Komentar.in.ua
- Google Maps / Google Reviews

Важно: Vidhuk.ua сейчас является самым стабильным источником для прямых ссылок на конкретные отзывы. Для 048.ua часть отзывов может подгружаться через JavaScript, поэтому в текущей версии приложение хранит активную ссылку на страницу отзывов/источника, а не всегда на отдельный отзыв.

## Основные страницы

- Бренды: краткая сводка по Amebli, Sofino и Matrasroll.
- Лента: список найденных отзывов и упоминаний.

- Рейтинг: таблица Vidhuk.ua + Google по вашим сайтам и конкурентам.

## Telegram-уведомления

Ежедневные Telegram-уведомления о рейтингах и негативных отзывах настроены через Perplexity Computer и Telegram-коннектор.

Текущая логика автоматизации:

- каждый день в 09:00 по Киеву отправляется короткое резюме в Telegram-группу Price;
- по каждому бренду выводится рейтинг Vidhuk.ua и Google;
- динамика обозначается так:
  - 🟢 без изменений;
  - 🟢↑ рейтинг вырос;
  - 🔴↓ рейтинг упал;
- ниже добавляется список новых негативных отзывов;
- если нового негатива нет, отправляется короткая строка: `Негатив: новых негативных отзывов нет`.

Эта автоматизация не является частью локального Node.js-приложения в архиве. Если переносить проект на отдельный сервер, Telegram-логику нужно будет вынести в отдельный cron/worker и подключить Telegram Bot API.

## Google Ratings

Google-рейтинги в текущей версии используются для сводной таблицы рейтингов. В автоматическом мониторинге Google-данные получаются через Google Maps Platform connector.

Если переносить проект на собственный сервер, потребуется:

1. Создать Google Maps Platform API key.
2. Подключить Places API.
3. Вынести place_id брендов в конфигурацию.
4. Реализовать регулярный сбор рейтинга и количества отзывов.

## Что не включено в архив

Архив для GitHub специально не содержит:

- `node_modules`
- `dist`
- локальную SQLite-базу `data.db`
- `.env`
- временные файлы и скриншоты

Это сделано, чтобы репозиторий был чистым и безопасным для публикации.
